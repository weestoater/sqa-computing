## what sort of projects do pupils have to build websites for

The specification doesn't prescribe specific website themes. Instead, the assignment typically presents a client scenario and asks candidates to analyse requirements, design, implement, test and evaluate a solution.

Looking at recent Higher Computing Science assignments, the projects tend to be fairly realistic but modest in scope. Common examples include:

- Local community organisations
- Sports clubs
- Tourist attractions
- Charities
- Events and festivals
- Educational resources
- Small businesses
- Hobby or interest groups

The emphasis is usually on demonstrating the development process rather than creating a commercially realistic website. Candidates need to show they can:

- interpret requirements
- create page layouts and navigation
- use HTML, CSS and JavaScript
- collect and display information
- validate user input
- test their solution
- evaluate it against the original requirements

A typical Higher-level website might contain:

- Home page
- About page
- Contact page with a form
- Navigation menu
I- mage gallery
- Interactive JavaScript feature (quiz, calculator, filtering, validation, etc.)
- Consistent styling through CSS

For example, a candidate might be asked to build:

- A website for a wildlife reserve
- A school sports day information site
- A music festival website
- A museum visitor information site
- A local tourism guide

The assignment marking focuses far more on evidence of analysis, design, implementation, testing and evaluation than on the visual sophistication of the finished site. A technically correct, well-documented website can score highly even if it looks fairly simple.

If you're interested in the exact level expected, the best source is the recent assignment papers and electronic files on the Higher Computing Science page. They contain the actual client briefs, assets and marking instructions used for assessment.
